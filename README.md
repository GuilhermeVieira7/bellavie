# Bellavie Estética Avançada — Landing Page

Landing page da Bellavie Estética Avançada (Dra. Ana Paula Feitosa · Parauapebas – PA).

Site estático (HTML + CSS + JS puro), sem build. Todos os botões abrem o WhatsApp **(94) 98102-9258** com mensagem pronta.

## Deploy na Vercel
1. Acesse vercel.com → **Add New… → Project**
2. Importe o repositório `GuilhermeVieira7/bellavie`
3. Framework Preset: **Other** · Build Command: vazio · Output Directory: vazio
4. **Deploy**. A cada `git push` na `main`, o site é atualizado automaticamente.

## Editar
- Telefone do WhatsApp: variável `PHONE` no final do `index.html`
- Fotos: pasta `assets/`
